# AI-бот в ВКонтакте

AI-бот для сообщества ВКонтакте на LongPoll API. Отвечает на сообщения с помощью
нейросети через OpenRouter, ведёт несколько независимых диалогов, поддерживает
шесть режимов общения и долгосрочную память о пользователе в виде фактов.

Кейс «VPf09. Кейс 1: AI-бот в VK», продвинутый вариант (своя задача).

## Возможности

- **6 режимов общения** — «Обычный помощник», «Программист», «Преподаватель»,
  «Бизнес-консультант», «Дружелюбный собеседник» и «Ментор по Python».
  Режим привязан к диалогу, у каждого режима свой system prompt.
- **Несколько диалогов** — создание, переключение, переименование и удаление.
  Единственный диалог удалить нельзя. У пользователя может быть не больше
  8 диалогов: это предел клавиатуры ВК (не больше 10 рядов кнопок), лимит
  настраивается переменной `MAX_DIALOGS`. История и режим у каждого диалога свои.
- **Краткосрочная память** — в контекст запроса попадают до 100 последних
  сообщений активного диалога, хранится также не больше 100.
- **Долгосрочные факты** — команда `Запомни: <текст>` сохраняет факт о
  пользователе, кнопка «🧠 Факты обо мне» показывает список и позволяет его
  очистить. До 20 фактов по 200 символов; факты переживают перезапуск бота и
  подмешиваются в system prompt любого диалога и режима.
- **Inline-клавиатуры** — главное меню, список диалогов, выбор режима,
  настройки, управление фактами.
- **Статус «печатает…»** — пока нейросеть готовит ответ.
- **Обработка ошибок** — пустое и слишком длинное сообщение (лимит 4000
  символов) отклоняются без запроса к API; при ошибке OpenRouter бот отвечает
  запасным сообщением и не падает.

## Структура проекта

```text
main.py                      — точка входа: проверка настроек, сборка сервисов и Bot, run()
config/settings.py           — загрузка .env, Settings, шесть режимов, NO_MARKDOWN_RULE
models/entities.py           — dataclasses Message, Dialog, UserProfile и сериализация
storage/user_store.py        — JSON-хранилище users/<user_id>.json, атомарная запись
services/ai_service.py       — клиент OpenRouter (AsyncOpenAI), сборка контекста, fallback
services/dialog_service.py   — создание/переключение/переименование/удаление диалогов
services/facts_service.py    — добавление/очистка фактов, блок фактов для system prompt
keyboards/menus.py           — inline-клавиатуры: меню, диалоги, режимы, настройки, факты
bot/handlers.py              — обработчики кнопок и текста, FSM переименования, лимиты
utils/typing.py              — индикатор «печатает…» (messages.setActivity)
utils/locks.py               — блокировки по владельцу профиля (from_id): сериализация действий пользователя
tests/                       — 31 unittest-тест без сети
requirements.txt             — зависимости
.env.example                 — шаблон переменных окружения без секретов
users/                       — runtime-данные пользователей (создаётся автоматически,
                               в git не попадает)
```

## Установка

Требуется Python 3.11 (проверено на 3.11.9). Зависимости ставятся в отдельное
окружение проекта `.venv`.

### Windows

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> **Важно:** не устанавливайте `requirements.txt` в глобальный интерпретатор.
> `vkbottle` 4.11 требует `pydantic>=2.13.4` и `aiohttp>=3.14.3`, а глобальный
> `aiogram` 3.15 — `pydantic<2.10` и `aiohttp<3.11`. Установка в global обновит
> эти пакеты и сломает aiogram. Подробнее — в разделе «Возможные проблемы».

### Настройка .env

Скопируйте шаблон и заполните значения:

```bat
copy .env.example .env
```

```powershell
Copy-Item .env.example .env
```

```bash
cp .env.example .env
```

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `VK_TOKEN` | да | — | токен доступа сообщества ВКонтакте |
| `OPENROUTER_API_KEY` | да | — | API-ключ OpenRouter |
| `OPENROUTER_MODEL` | нет | `google/gemini-2.5-flash-lite` | модель OpenRouter |
| `MAX_MESSAGE_LEN` | нет | `4000` | лимит длины сообщения пользователя |
| `MAX_HISTORY` | нет | `100` | сколько последних сообщений диалога хранить и передавать |
| `MAX_DIALOGS` | нет | `8` | максимум диалогов у пользователя (предел клавиатуры ВК) |
| `USERS_DIR` | нет | `users` | каталог JSON-файлов пользователей |

**Токен ВК:** Управление сообществом → Работа с API → Ключи доступа → создать
ключ. В разделе LongPoll API включите LongPoll, в настройках «Сообщения
сообщества» разрешите сообщения.

**Ключ OpenRouter:** создаётся в личном кабинете OpenRouter (openrouter.ai).

Секреты хранятся только в `.env`; файл исключён из git. В репозиторий попадает
только `.env.example` без значений ключей.

## Запуск

Из корня проекта:

```bat
.venv\Scripts\python.exe main.py
```

Либо после активации `.venv`:

```bat
python main.py
```

Перед запуском включите VPN: OpenRouter блокирует запросы с российских IP
(см. «Возможные проблемы»). Если `VK_TOKEN` или `OPENROUTER_API_KEY` не заданы,
бот завершится с сообщением в логе.

## Тесты

Из корня проекта, Windows:

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Linux / macOS (после активации `.venv`):

```bash
python -m unittest discover -s tests -v
```

31 тест, сеть не требуется. Проверяются: импорт модулей и главное меню, шесть
режимов (включая «Ментор по Python»), хранилище и восстановление битого JSON,
починка профилей без диалогов и с несуществующим активным диалогом,
CRUD диалогов и лимит в 8 диалогов (меню укладывается в 10 рядов кнопок ВК),
сериализация действий пользователя блокировкой по владельцу профиля (`from_id`), лимиты и
дедупликация фактов, вставка фактов в system prompt, лимит истории, успешный
ответ и fallback при ошибке API. Ожидаемый результат: `OK`.

Тест fallback намеренно вызывает ошибку API: сообщение «OpenRouter request
failed» уровня ERROR перехватывается `assertLogs` и не считается сбоем.
Трассировка в выводе не появляется.

## Чек-лист скриншотов для сдачи

Перед съёмкой: VPN включён, бот запущен, других процессов бота с тем же токеном
нет.

1. **Главное меню** — нажмите «❓ Помощь» (или отправьте любое сообщение):
   видна inline-клавиатура с кнопками «🆕 Новый диалог», «📋 Мои диалоги»,
   «🎭 Сменить режим», «🧠 Факты обо мне», «⚙️ Настройки», «❓ Помощь».
2. **Список диалогов** — создайте 2–3 диалога и откройте «📋 Мои диалоги»:
   видны кнопки диалогов, активный отмечен «✅», есть «✏️ Переименовать»,
   «🗑 Удалить», «🆕 Новый».
3. **Ответ в режиме «Ментор по Python»** — «🎭 Сменить режим» → «Ментор по
   Python», затем задайте вопрос по Python (например: «Объясни цикл for и дай
   маленькое задание»). На скриншоте — подтверждение смены режима и ответ в
   стиле ментора.
4. **Настройки сообщества / токен** — страница сообщества с токеном
   (Управление → Работа с API). Токен на скриншоте обязательно замаскируйте:
   полный ключ публиковать нельзя.

Дополнительно (по желанию): отправьте `Запомни: учусь на вайб-кодера`, затем
откройте «🧠 Факты обо мне» — на скриншоте виден сохранённый факт и кнопка
очистки.

## Возможные проблемы

### OpenRouter отвечает 403, бот пишет «Нейросеть временно недоступна»

OpenRouter геоблокирует запросы с российских IP — без VPN возвращается
HTTP 403. Включите VPN и перезапустите бота. Любая ошибка API (403, сеть,
неверный ключ, закончились средства) перехватывается: бот отвечает
«⚠️ Нейросеть временно недоступна. Попробуйте ещё раз через минуту.», причина
пишется в лог. Проверьте также, что ключ OpenRouter действителен и модель
доступна.

### Бот отвечает дважды

С одним токеном ВК работает только один процесс бота. Если запущены два
процесса (например, прошлый запуск не остановлен или параллельно работает
другой бот с тем же токеном), LongPoll доставляет сообщение обоим и оба
отвечают. Остановите лишние процессы: Диспетчер задач → Python, либо в
командной строке:

```bat
tasklist | findstr python
```

Оставьте ровно один процесс.

### Конфликт pydantic/aiohttp с глобальным aiogram

`vkbottle` 4.11 требует `pydantic>=2.13.4` и `aiohttp>=3.14.3`, а `aiogram` 3.15
(глобальное окружение) — `pydantic<2.10` и `aiohttp<3.11`. Если поставить
зависимости этого проекта в глобальный Python, pydantic и aiohttp обновятся и
aiogram перестанет импортироваться. Решение: запускайте проект только через
`.venv` (команды выше) и не выполняйте `pip install -r requirements.txt` без
активированного `.venv`. Если глобальное окружение уже изменено, восстановите
совместимые с aiogram версии pydantic и aiohttp в глобальном Python.

### Бот не запускается сразу после старта

Проверьте лог: при отсутствии `VK_TOKEN` или `OPENROUTER_API_KEY` в `.env`
бот завершается с понятным сообщением. Убедитесь, что `.env` лежит в корне
проекта рядом с `main.py`.
