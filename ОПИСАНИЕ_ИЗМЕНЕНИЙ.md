# Описание изменений

Кейс «VPf09. Кейс 1: AI-бот в VK», продвинутый вариант (своя задача).
Документ закрывает п. 3 продвинутого задания: что добавлено, как работает,
какие файлы созданы и изменены, почему выбран провайдер и модель, какой режим
демонстрируется.

## 1. Новый режим общения «Ментор по Python»

Шестой режим `python_mentor` добавлен к пяти базовым. Описан в
`config/settings.py` как ещё одна запись в словаре `MODES`; отдельного кода
режим не требует — клавиатура режимов строится циклом по `MODES`, поэтому
кнопка «Ментор по Python» появляется автоматически.

Что делает режим: ведёт ученика пошагово. Сначала объясняет идею, затем
показывает маленький пример, затем просит ученика попробовать самому и
проверяет результат. Ошибки разбирает по одной, хвалит за прогресс, домашнее
задание целиком не решает — задаёт наводящие вопросы. Уровень объяснений —
начинающий.

Чем отличается от других режимов:

- **«Программист»** — отвечает на вопрос и сразу даёт готовый пример кода;
  «Ментор по Python» не выдаёт готовое решение, а ведёт к нему шагами и
  проверяет, что ученик попробовал сам.
- **«Преподаватель»** — универсальный учебный режим по любому предмету;
  «Ментор по Python» предметный: Python, практические примеры, разбор ошибок
  в коде, уровень новичка.
- Режим привязан к диалогу: смена режима через «🎭 Сменить режим» меняет
  только активный диалог, история и остальные диалоги не затрагиваются.

Проверки: `tests/test_settings.py` (режим существует, всего шесть режимов),
`tests/test_imports.py` (кнопка «Ментор по Python» есть в меню режимов).

## 2. Долгосрочные факты о пользователе

Фича добавляет память, которая не зависит от истории диалога и переживает
перезапуск бота.

### Как добавить факт

Любое сообщение, начинающееся с `Запомни:` (регистр не важен), сохраняет факт:

```text
Запомни: меня зовут Вал
```

Обработчик отрезает текст после двоеточия и передаёт его в `FactsService.add`;
сервис обрезает факт до 200 символов. Бот отвечает «Запомнил: <факт>» и показывает
текущий список. Если текста после `Запомни:` нет, достигнут лимит или такой
факт уже сохранён (сравнение без учёта регистра), бот объясняет причину отказа.

### Как посмотреть и очистить

Кнопка «🧠 Факты обо мне» в главном меню показывает список сохранённых фактов
(или подсказку, если список пуст). Если факты есть, в клавиатуре появляется
кнопка «🗑 Очистить факты» — она удаляет весь список; отдельного подтверждения
нет. Кнопка «◀️ Назад» возвращает главное меню.

### Лимиты и хранение

- Не более 20 фактов (`MAX_FACTS = 20`).
- Каждый факт обрезается до 200 символов (`MAX_FACT_LENGTH = 200`).
- Пустые факты и дубликаты игнорируются.
- Факты лежат в JSON пользователя `users/<user_id>.json` в поле `facts`,
  рядом с диалогами, и сохраняются атомарной записью (`UserStore.save`).

### Вставка в system prompt

Факты не отправляются отдельными сообщениями и не занимают историю диалога.
При каждом обычном сообщении обработчик вызывает `FactsService.build_block` и
передаёт результат в `AIService.ask`. `AIService.build_context` собирает
system-сообщение в порядке: system prompt режима + блок фактов + правило
«без Markdown». Поэтому факты действуют в любом диалоге и любом режиме, в том
числе в новых диалогах; при пустом списке блок пустой и ничего не меняет.

Проверки: `tests/test_facts.py` (пустой факт, обрезка до 200, дубликаты, лимит
20, формат блока), `tests/test_ai_service.py` (блок фактов попадает в
system-сообщение), `tests/test_storage.py` (поле `facts` в профиле по умолчанию
и в сохранённом JSON).

## 3. Созданные и изменённые файлы

Проект собран с нуля по заданию кейса. Ниже — состав файлов и назначение
каждого; режим `python_mentor` и фича фактов — дополнения продвинутого
варианта.

Дополнительно: создание диалогов ограничено 8 (геометрия клавиатуры ВК — не
больше 6 рядов кнопок), а действия одного пользователя сериализуются
блокировкой по владельцу профиля (`from_id`, `utils/locks.py`), чтобы параллельные апдейты
vkbottle не теряли изменения профиля.

| `models/entities.py` | Dataclasses `Message`, `Dialog` (поле `mode_id`), `UserProfile` (поле `facts`), методы `to_dict`/`from_dict`. |

## 4. Почему Tokenator Cloud и модель `deepseek-v4.1-flash-1017`

**Tokenator Cloud** (`https://api.tokenator.cloud/v1`) выбран заказчиком вместо
провайдера из урока (ProxyAPI) и вместо OpenRouter. Причины:

- API совместим с OpenAI, поэтому используется уже знакомая библиотека
  `openai` (`AsyncOpenAI`) — отдельный SDK не нужен.
- Провайдер доступен с российских IP без VPN, в отличие от OpenRouter,
  который возвращает HTTP 403.
- Один ключ даёт доступ к разным моделям, а модель и адрес API меняются
  переменными окружения `OPENROUTER_MODEL` и `OPENROUTER_BASE_URL`, без правок
  кода.

**Модель `deepseek-v4.1-flash-1017`** — текущее значение `OPENROUTER_MODEL` в
`.env`:

- быстрая и достаточная для учебного чата с короткими запросами;
- корректно держит system prompt: роль режима, факты и правило «без Markdown»;
- легко заменить через `OPENROUTER_MODEL`, если понадобится другая модель.

Дефолт в коде — `google/gemini-2.5-flash-lite` и
`https://openrouter.ai/api/v1` (сценарий OpenRouter); `.env` переопределяет их
на Tokenator Cloud. При любой ошибке API бот не падает, а отвечает запасным
сообщением «⚠️ Нейросеть временно недоступна…» и пишет причину в лог. Для
OpenRouter потребовался бы VPN из-за 403 с российских IP; Tokenator работает
без него.

## 5. Демонстрация

Для показа выбран режим **«Ментор по Python»** (`python_mentor`) — новый режим
продвинутого задания; на нём же удобно показать работу фактов.

Рекомендуемый сценарий для скриншотов (провайдер доступен, запущен один процесс бота):

1. Отправить боту любое сообщение или нажать «❓ Помощь» — появится главное
   меню. Скриншот: главное меню со всеми шестью кнопками.
2. Нажать «🆕 Новый диалог» 1–2 раза, затем «📋 Мои диалоги» — виден список
   диалогов, активный отмечен «✅». Скриншот: список диалогов.
3. Нажать «🎭 Сменить режим» → «Ментор по Python», задать вопрос по Python,
   например: «Объясни, как работает цикл for, и дай маленькое задание».
   Скриншот: подтверждение смены режима и ответ в стиле ментора (объяснение →
   пример → предложение попробовать).
4. Отправить «Запомни: учусь на вайб-кодера», затем нажать «🧠 Факты обо мне».
   Дополнительный скриншот: сохранённый факт и кнопка «🗑 Очистить факты».
5. Создать новый диалог и спросить «Что ты обо мне знаешь?» — бот использует
   сохранённый факт, что показывает работу памяти между диалогами.
6. Скриншот страницы сообщества с токеном (Управление → Работа с API): токен
   обязательно замаскировать, полный ключ публиковать нельзя.
