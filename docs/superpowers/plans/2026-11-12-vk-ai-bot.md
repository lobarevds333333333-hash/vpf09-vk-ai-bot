# AI-бот в ВК (VPf09, продвинутое задание) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать VK LongPoll AI-бота по спецификации урока с 6 режимами, многодиалоговостью, JSON-памятью и долгосрочными фактами о пользователе через OpenRouter.

**Architecture:** Слоистая структура: `models` (dataclasses) → `storage` (JSON на пользователя) → `services` (диалоги, факты, AI) → `keyboards`/`bot` (VK-интерфейс) → `main.py`. Контекст LLM собирается на каждый запрос: system prompt режима + блок фактов + последние ≤100 сообщений активного диалога.

**Tech Stack:** Python 3.11, vkbottle ≥4.10 (LongPoll), python-dotenv, openai ≥1.40 (AsyncOpenAI → OpenRouter), aiohttp, unittest.

**Spec:** `docs/superpowers/specs/2026-11-12-vk-ai-bot-design.md`

## Global Constraints

- Python 3.11; зависимости: `vkbottle>=4.10.0`, `python-dotenv>=1.0.0`, `openai>=1.40.0`, `aiohttp>=3.10.0`. Новых зависимостей не добавлять.
- Хранилище — только JSON: `users/<user_id>.json`. Никаких SQLite/PostgreSQL.
- Только LongPoll API, без Callback/вебхуков.
- OpenRouter: `base_url="https://openrouter.ai/api/v1"`, модель из `OPENROUTER_MODEL`, дефолт `google/gemini-2.5-flash-lite`.
- Лимиты: сообщение ≤ 4000 символов, история ≤ 100 сообщений, факты ≤ 20 шт. по ≤ 200 символов.
- Весь пользовательский текст и промпты — на русском; в system prompt запрещён Markdown.
- Секреты только в `.env` (gitignored); `.env.example` без значений. Значения ключей никогда не печатать в консоль.
- Все вызовы LLM — асинхронные; при любой ошибке API бот отвечает fallback-текстом и не падает.

## Review Focus

1. Сообщение `Запомни:` без текста — бот не должен падать и не должен сохранять пустой факт.
2. Попытка удалить единственный диалог — отказ с уведомлением, диалог остаётся.
3. Битый JSON в `users/<id>.json` — файл уходит в `.bak`, профиль создаётся заново, бот работает.
4. Ошибка/таймаут OpenRouter — fallback-ответ, бот продолжает принимать сообщения.
5. История длиннее 100 сообщений — в модель уходят только последние 100, файл не растёт бесконечно.
6. Сообщение длиннее 4000 символов — вежливый отказ без вызова LLM.
7. Переименование в пустую строку — сохраняется прежнее название.
